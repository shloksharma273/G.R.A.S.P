Turn a robot's manual into a rulebook.

A manual is the opposite of a how-to video. Narration skips the preconditions; documentation is largely made of them — the GPS lock, the battery minimum, the safety switch. Point it at source code instead and every step carries the handle a program calls to run it, so the plan says which service, not just what to do. Either way the gate has the last word.
