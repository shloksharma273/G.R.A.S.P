From rulebooks to a robot that takes orders.

Every project here goes through the same four stages. Build them all from this page: tick rulebooks, name a project, check it, build. Or pick a project up at whichever stage it has already reached in AutoGraph. Each card below shows how far a project has got and what comes next.

  1. 1 Corpus graph AutoGraph · or here

    Your rulebooks are uploaded as one module, embedded, linked by similarity and clustered. This is the map of what you gave it.

  2. 2 Knowledge graph AutoGraph · or here

    Each cluster is read for four kinds of entity — skills, primitives, objects and states — and the relationships between them.

  3. 3 PlanGraph here

    Those relationships become preconditions, effects and an order, one scoped subgraph per skill. This is the only stage that writes, so it is checked first.

  4. 4 Ask for a plan here

    Type a command in plain English and get back the ordered steps, each with the service, topic or action that runs it.
